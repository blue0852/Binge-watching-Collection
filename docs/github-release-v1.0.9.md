# Public Domain Cinema v1.0.9

Windows 桌面版（内置本地服务，无需单独安装 Node.js）。

本版是**播放体验升级版**：新增系统级置顶画中画窗口，重做播放器控制界面，并修掉若干播放状态问题。

## 下载

| 文件 | 说明 |
|------|------|
| `Public Domain Cinema-1.0.9-portable.exe` | **便携版**：双击即用，配置保存在 exe 同目录的 `config.json` |
| `Public Domain Cinema-1.0.9-setup.exe` | **安装版**：配置保存在 `%APPDATA%\Public Domain Cinema\config.json` |

> 安装包未做代码签名，Windows 可能提示「未知发布者」，选择仍要运行即可。

## 本版更新

### 画中画

- 新增**置顶画中画窗口**：播放器上点画中画按钮，视频浮在其它窗口之上，可边看边做别的事。
- 画中画窗口里保留**完整进度条**与**上一集 / 下一集**，不是系统默认的简化控件。
- 画中画开启后，主窗口的视频自动暂停并静音，不会再出现两处同时播放。
- 关闭画中画后，主窗口自动接回画中画里的最新进度和集数继续播。

### 播放界面

- 播放器改用自绘控制条（播放 / 暂停、进度条、时间、倍速、音量、画中画、全屏），
  不再是浏览器默认控件，样式与站点统一。
- 暂停时显示大号圆形播放按钮，缓冲时显示加载指示。
- 控制条播放中自动隐藏，鼠标移入或按键即出现。
- 新增键盘快捷键：`空格`/`K` 播放暂停、`←`/`→` 快退快进 10 秒（按住 Shift 为 30 秒）、
  `↑`/`↓` 音量、`M` 静音、`F` 全屏、`N`/`P` 下一集 / 上一集；双击画面全屏。
- 倍速与音量设置会记住，换片后依然生效。

### 小窗

- 小窗（右下角悬浮播放器）补充了进度条与上一集 / 下一集。
- 小窗改为**只能主动开启**：点播放器上的「小窗」按钮才进入；
  从播放页返回列表时不再自动弹出小窗，播放随之停止。

### 修复

- 修复画中画开启后，主窗口里的视频仍在后台播放的问题。
- 修复小窗控制条不会自动隐藏、挡住画面的问题。
- 修复连续按方向键时快进快退被重复触发（一次跳 30 秒）的问题。

## 功能概览

- 多资源站切换、分类筛选、搜索与分页
- 详情页多线路 / 选集，m3u8 使用 hls.js
- 播放历史、片头片尾跳过、顶栏缓存刷新
- 站点管理与 `config.json` 配置

## 从源码构建

```bash
npm install
npm run pack:win
```

产物位于 `release/` 目录（不纳入 Git，请在本 Release 附件中下载 exe）。
