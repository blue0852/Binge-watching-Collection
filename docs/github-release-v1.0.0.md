# Public Domain Cinema v1.0.0

Windows 桌面版（内置本地服务，无需单独安装 Node.js）。

## 下载

| 文件 | 说明 |
|------|------|
| `Public Domain Cinema-1.0.0-portable.exe` | **便携版**：解压即用，配置保存在 exe 同目录的 `config.json` |
| `Public Domain Cinema-1.0.0-setup.exe` | **安装版**：配置保存在 `%APPDATA%\Public Domain Cinema\config.json` |

> 安装包未做代码签名，Windows 可能提示「未知发布者」，选择仍要运行即可。

### m3u8 专项优化（2026-09 更新）

- **TS 分片内存缓存**：已拉取的分片可本地命中，拖动/重缓冲更快。
- **m3u8 清单短缓存**、上游 **Keep-Alive**，连续分片延迟更低。
- **hls.js**：首个分片缓冲后起播、自动重试、预取与更大缓冲。

### 体验与性能

- 顶栏 **刷新** 按钮：一键清空 API / 流媒体缓存并重新加载。
- **站点切换**：后端缓存容量上限，减少长时间切换后变卡。
- 分类/站点列表请求去重，减少重复 API。

### 播放更流畅

- **流媒体代理流式转发**：TS / MP4 边下边传，不再整段缓冲后再播放，起播与切分片更顺。
- **支持 Range 请求**：MP4 拖动进度条时按需拉取，减少等待。
- **HLS 缓冲优化**：开启分片预取与更大缓冲上限，降低代理链路下的卡顿概率。

### 全屏仍可切集

- 全屏作用于**播放器容器**（而非仅 `<video>`），全屏内保留**上一集 / 下一集**、集数角标、跳过片头/片尾。
- 控制条内提供**全屏 / 退出全屏**按钮（原生控件全屏已禁用，避免叠层丢失）。

### 其他

- 开发/调试桌面版时可通过环境变量 `CONFIG_PATH` 指定配置文件路径。

## 功能概览（应用整体）

- 多资源站切换、分类筛选、搜索与分页
- 详情页多线路 / 选集，m3u8 使用 hls.js
- 播放历史、片头片尾跳过、连续播放
- 站点管理与 `config.json` 配置

## 从源码构建

```bash
npm install
npm run pack:win
```

产物位于 `release/` 目录（该目录不纳入 Git，请在本 Release 附件中下载 exe）。
