# Public Domain Cinema v1.0.4

Windows 桌面版（内置本地服务，无需单独安装 Node.js）。

本版为**性能与安全修复版**，不改变界面结构，主要解决搜索长时间无响应、桌面版偶发卡死等问题。

## 下载

| 文件 | 说明 |
|------|------|
| `Public Domain Cinema-1.0.4-portable.exe` | **便携版**：解压即用，配置保存在 exe 同目录的 `config.json` |
| `Public Domain Cinema-1.0.4-setup.exe` | **安装版**：配置保存在 `%APPDATA%\Public Domain Cinema\config.json` |

> 安装包未做代码签名，Windows 可能提示「未知发布者」，选择仍要运行即可。

## 本版更新

### 速度

- **全站搜索**：65.7 秒 → 约 7 秒（首次），重复搜索约 7 毫秒。超时后返回已拿到的结果，不再整页等待。
- **Internet Archive**：65 秒无响应 → 约 10 秒，失败结果也会缓存，短时间内不再重复超时。
- **首屏体积**：单包 782 KB → 187 KB，播放器（hls.js）改为进入详情页才加载。
- **资源站延迟探测**：21 秒 → 4.4 秒，并写入本地文件，重启后直接复用，不再每次启动都探测全部站点。

### 稳定性

- 修复桌面版长时间播放后卡死的问题（后端日志管道背压导致事件循环阻塞）。
- 修复上游请求超时设置实际未生效的问题，现在会按设定时间真正中断。
- 修复极速资源站中已带扩展名的播放地址被错误改写为 `/index.m3u8` 的问题。

### 安全

- 本地服务只监听 `127.0.0.1`，不再对局域网开放。
- 图片与流媒体代理拒绝内网/回环地址（防 SSRF），图片单张上限 8 MB。
- 配置文件改为原子写入，损坏时可回退到上次可用配置。

### 其他

- 资源站由 49 个精简为 35 个：移除 12 组同主机重复站点与 2 个失效站点，卡片不再重复。
- 请求日志默认关闭，需要时设置环境变量 `LOG_REQUESTS=1` 开启。
- 静态资源启用 1 年强缓存，二次打开更快。
- 新增 404 页面与错误边界，单页异常不再整站白屏。
- 播放进度改为按整秒写入，减少无谓写盘。

## 功能概览

- 多资源站切换、分类筛选、搜索与分页
- 详情页多线路 / 选集，m3u8 使用 hls.js
- 播放历史、片头片尾跳过、顶栏缓存刷新
- 站点管理与 `config.json` 配置

## 从源码构建

```bash
npm install
npm run pack:win
```

产物位于 `release/` 目录（不纳入 Git，请在本 Release 附件中下载 exe）。
